# 🌸 Kawaii Money

แอปรายรับรายจ่ายบัตรเครดิตแบบน่ารัก สำหรับ iPhone ไม่มี AI ไม่มีค่าใช้จ่ายรายเดือน ข้อมูลอยู่ใน Google Sheet ของคุณเอง

- `apps-script/Code.gs` — หลังบ้าน (วางใน Apps Script ของชีต แล้วรัน `setup`)
- `docs/` — หน้าแอป PWA (GitHub Pages เปิดจากโฟลเดอร์นี้ แล้วเพิ่มลงหน้าจอโฮม)
  - `parsers.js` อ่านใบแจ้งยอด UOB, `core.js` กฎจัดหมวดและการจับคู่ (สร้างจาก Code.gs ด้วย `node tests/build-core.js`)
- `tests/` — ทดสอบตัวอ่านใบแจ้งยอดและตรรกะหลังบ้าน (`node tests/parser.test.js`, `node tests/backend.test.js`)
- `SETUP.md` — คู่มือติดตั้งทีละขั้น

ฟีเจอร์: นำเข้า PDF ใบแจ้งยอด UOB และจับคู่กับรายการที่บันทึกระหว่างเดือน · อ่านอีเมล Grab แยก Food/Transport ·
ปุ่มลัด "ของแฟน" สำหรับ 7-11 · ป้ายช่องทาง (Shopee, Grab, 7-11, BTS/MRT) · แบ่งยอดบิลเดียวหลายหมวด ·
หมวดตั้งเองไม่จำกัด แก้/รวม/ซ่อนได้ · กฎจำร้านและผู้รับโอน · งบรายหมวด · บัตรหลายใบพร้อมรอบตัดและวันครบกำหนด ·
เงินสด เงินโอน รายการประจำ · ภาพรวมแบบโดนัทและกราฟแท่ง · ภาษาไทย/อังกฤษ · โหมดมืด
